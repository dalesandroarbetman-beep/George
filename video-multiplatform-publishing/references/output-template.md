# Output Template

Keep this order and heading text. Replace bracketed placeholders with observed or user-supplied information. If a field is unknown, write `未提供` and explain what would resolve it.

## 一、视频分析

- **可确认事实**：时长、画幅、场景、产品、叙事结构、镜头/拍摄手法、贯穿标题或字幕。
- **内容形态**：展示型 / 开箱型 / 制作过程型 / 口播型 / 选择仪式型。
- **受众判断**：C 端或 B 端；把依据写成推断。
- **待确认项**：产品事实、链接、品牌名、时区、账号数据或素材缺口。

## 二、TikTok

1. 主推文案（英文） + 中文翻译
2. 备用文案（不同角度）
3. 标签（5–10 个）
4. 发布设置：时段、封面、BGM、置顶评论、下载水印

## 三、Instagram Reels

同上四块，并补充 Save 引导、色系/穿搭角度和 Story 互动建议。

## 四、YouTube Shorts

同上四块，并确保标题前几词有点击钩子，搜索词只使用视频真实支持的词。

## 五、Facebook

同上四块，并可给出清单/送礼/编号投票和小预算测试建议。

## 六、X

同上四块；主推文案最终渲染后不超过 280 字符。

## 七、DIY 垂类账号

同上四块；以选料、组装或制作方法论为主，不复制主号卖货文案。

## 八、UTM 链接矩阵

Use:

`https://lnk.bio/{brand}?utm_source={platform}&utm_medium=organic&utm_campaign={campaign}&utm_content={content}`

Provide one row per platform. Keep `{brand}`, `{campaign}`, and `{content}` as explicit placeholders when the user has not supplied them.

## 九、评论区运营话术

Provide 6–8 pairs of English and Chinese prompts covering some of: pinned vote, inquiry, customization, material/length, finished piece versus DIY, tagging a friend, and gifting.

## 十、发布节奏与检查清单

- Release order and staggered times with timezone.
- 48–72 hour checks: views, retention, completion, saves, shares, comments, profile visits, link clicks, and qualitative replies.
- Series hooks: recurring title/subtitle, color or material memory point, and next-video variations.
- Preflight: captions, translation, links, hashtags, cover, music rights, watermark, facts, and sensitive-file exclusion.
