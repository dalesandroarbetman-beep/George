# 标题与风险闸门

优先顺序为：`系列 + 造型 + 装饰/材质 + 款式 + 成色/主体材质`。只使用商品资料、用户确认或清晰图片支持的词。默认输出三组中文标题候选；不把货号、品牌、授权、专利、独家、爆款等放入标题。

风险判断采用“规则初筛 + 人工复审”。普通字母、十字、骷髅、爱心、链条和基础几何造型本身不自动判风险，也不因为这些常见元素阻止资料检查。发现疑似仿大牌、品牌标识或受保护的独特设计时，标记人工复审；状态为 `品牌/IP风险待确认` 时暂停自动提交，确认属于仿牌或侵权时使用 `PASS/禁止上架`。

纯规则程序无法可靠完成复杂图片侵权判断。风险证据不足时，状态为 `风险无法确认`，标题候选为空并请求人工审核。资料字段冲突时保留冲突内容，状态为 `资料冲突待确认`。材质证据不足时可用 `材质待确认`，但不得补写天然、合成、镀层、纯度等宣传。

`18K` 只能按资料中的原词保留，不得自行解释为足金或镀金；资料写有 18K 但没有材质时，应标记材质待确认。图片清晰显示锆石且资料没有装饰材质时，可按既定规则加入 `锆石`，图像不清晰则只写入备注。

保存 `status`、`risk_summary`、`new_keywords`、`notes`，并将任何新词或不确定词从已确认词库中分离出来，交人工确认。
