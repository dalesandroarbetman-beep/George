# Confirmed Reusable Keyword Rules

来源：2026-09-14 维护者日志。以下词可在证据满足时复用；它们不是无条件添加词。

| 关键词 | 使用条件 |
|---|---|
| 滴釉 | 商品资料明确写明，或用户确认该工艺 |
| 叠戴 | 商品确实为双层/多层佩戴结构；单吊坠或单链不使用 |
| 不规则 | 图片或资料清楚显示非规则形态 |
| 蛇骨链 | 图片或资料清楚显示蛇骨链结构 |
| 女王头像 | 图片或资料清楚显示女王头像图案 |
| 万能扣 | 商品资料明确写明该配件用途 |
| 软陶 | 商品资料明确写明软陶材质 |
| 铜配件 | 商品资料明确写明铜材质或铜配件 |
| 镶嵌锆石 | 商品资料明确写明“锆石镶嵌”；仅图片显示锆石时，使用“锆石”而非“镶嵌锆石” |

补充：新词仍可开放候选使用，但必须在输出中记录 `new_keywords` 和 `keyword_sources`，不得静默写入确认词库。
