# GEO 基线评分规则 v1

总分 100，分为五个维度，每个维度 20 分。每个检查项按 `0–5` 打分，并保存证据与扣分原因。

| 维度 | 四个检查项 |
|---|---|
| 可发现性 | robots 可访问性、sitemap 完整性、核心页面可抓取性、详情页发现覆盖 |
| 可理解性 | 页面标题特异性、H1/标题层级、语言与翻译完整性、渲染正文可读性 |
| 可信度 | 品牌/实体一致性、联系与政策证据、结构化身份数据、主张的来源与日期 |
| 可引用性 | canonical 完整性、稳定 URL、正文可独立引用、结构化内容与去重信号 |
| 答案可用性 | 问题是否直接回答、关键限制是否明确、事实是否可追溯、搜索/AI 可提取性 |

统一锚点：`0` 表示缺失或无法验证；`1` 表示仅有零散信号；`2` 表示明显不足；`3` 表示基本可用但有重要缺口；`4` 表示整体可用且仅有局部缺口；`5` 表示抽样范围内完整且证据充分。使用中间整数时必须写明证据，不能凭总体印象给分。

报告必须注明扫描日期、页面样本、未检查范围和规则版本。复测时使用相同规则；若样本范围变化，需要同时报告范围差异，不能直接把两次总分当成趋势。
