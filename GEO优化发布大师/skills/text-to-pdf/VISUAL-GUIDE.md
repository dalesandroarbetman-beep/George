# 可视化选型决策指南

> 给 agent 的"读完原文 → 选最优呈现"决策逻辑。核心原则:**先判断数据的性质,再选可视化形态**——不是所有数字都该画图,也不是所有图都用柱状图。

---

## 一、决策表(数据特征 → 推荐呈现)

| 原文里出现的数据特征 | 最优呈现 | 用哪个组件 |
|---|---|---|
| **单个关键指标**(如"增长 2.4 倍""营收 666 万") | 大数字突出 | `.stat-hero` / `.kpi` |
| **2–3 个并列核心指标** | 并排数据卡 | `.kpi-row` |
| **2–6 项的数值对比**(如各渠道、各产品) | **柱状图** | SVG `<rect>` |
| **随时间变化的趋势**(月度、季度、年度) | **折线图** | SVG `<polyline>` |
| **占比 / 构成**(合计=100%,如市场份额) | **环形图** | SVG `<circle>`+dasharray |
| **完成度 / 百分比进度**(如各项达成率) | **进度条** | `.bars` |
| **先后顺序的步骤 / 流程** | 流程步骤 | `.steps` |
| **时间节点 / 里程碑 / 阶段** | 时间线 | `.timeline` |
| **多维度对比**(行×列,如客户类型×多属性) | **表格** + 状态标签 | `<table>` + `.pill` |
| **3–6 条并列要点 / 特性** | 要点网格 | `.grid c2/c3` |
| **涨跌 / 好坏 / 状态标记** | 彩色标签 | `.pill g/y/r`、`.delta up/down` |
| **一句关键结论 / 主张** | 高亮框 / 结论框 | `.callout`、`.takeaway` |

### 选型反例(别犯)
- **不要给只有 1–2 个数的内容画柱状图** → 用大数字 `.stat-hero` 更清晰
- **占比类不要用柱状图** → 用环形图,一眼看出"占多少"
- **超过 8 项的对比不要堆柱状图** → 用表格,柱子太多反而乱
- **没有可比性的零散数字不要硬画图** → 直接行文,或用 KPI 卡列举

## 二、图表 SVG 速查(可直接复制改数据)

### 柱状图 / 折线图
直接参考 `templates/visual.html` 中的现成示例(图 1-1 柱状、图 3-1 折线),复制后改数值、标签、柱高即可。柱高换算:`柱高px = 数值 / 最大值 × 可用高度`。

### 环形图(占比,新增)
```html
<div class="chart">
  <svg viewBox="0 0 200 200" xmlns="http://www.w3.org/2000/svg">
    <!-- 背景环 -->
    <circle cx="100" cy="100" r="70" fill="none" stroke="#eef1f5" stroke-width="26"/>
    <!-- 数据弧: 周长=2×π×70≈440; dasharray="占比×440  剩余×440" -->
    <!-- 例 65%: 0.65×440=286, 余 154 → "286 154" -->
    <circle cx="100" cy="100" r="70" fill="none" stroke="#0a6e6e" stroke-width="26"
            stroke-dasharray="286 154" stroke-linecap="round"
            transform="rotate(-90 100 100)"/>
    <text x="100" y="94" text-anchor="middle" font-size="30" font-weight="700" fill="#14213d">65%</text>
    <text x="100" y="116" text-anchor="middle" font-size="11" fill="#5c6573">核心占比</text>
  </svg>
  <div class="chart cap">图 X &nbsp;占比说明</div>
</div>
```
常用占比 → dasharray(周长 440):25%→`110 330` · 33%→`145 295` · 50%→`220 220` · 75%→`330 110`

### 多段环形(构成,如 A40%/B35%/C25%)
叠多个 `<circle>`,各自 `stroke-dasharray` 给本段长度、`stroke-dashoffset` 给起始位置(前面各段长度之和的负值),颜色区分。

### 进度条(占比/达成率)
用 `.bars` 组件(非 SVG):
```html
<div class="bars">
  <div class="bar"><div class="lab"><span>项目名</span><span class="v">78%</span></div>
    <div class="track"><div class="fill" style="width:78%"></div></div></div>
</div>
```

## 三、工作流提示

1. **先读懂原文的数据在表达什么**:是对比?趋势?占比?进度?——这决定图表类型
2. **查上表选组件**,复制 `visual.html` 或本指南的 SVG 模板
3. **改数据**:数值、标签、柱高/弧长/宽度百分比
4. **配色**统一用模板的 `--ink #14213d`(主)、`--accent #0a6e6e`(强调)、灰阶,不要乱加色
5. **每个图配一句图注**(`.chart .cap`),说明这图在讲什么
6. **数据必须忠于原文**,不臆造数值;不确定的占比/趋势宁可用表格列原始数字
