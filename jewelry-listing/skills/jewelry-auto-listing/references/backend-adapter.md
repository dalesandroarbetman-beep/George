# 后台适配器接口

后台适配器与上品准备程序分开维护。适配器可以是浏览器自动化程序，也可以是后台 API 客户端；更换后台时只替换适配器，不修改资料读取、图片索引、标题、标签或风险规则。

## 实施前置条件

在编写真实 adapter 前必须确认：后台产品名称与环境、字段清单和必填规则、分类/品牌/标签的真实选项值、图片上传接口、登录或 API 鉴权方式、创建后下架动作，以及测试商品的回滚办法。缺少任一项时只维护本合同和 dry-run 校验，不连接后台、不猜测选择器或接口。

## 输入

适配器只接收一个已经生成的 `上品包.json`。先调用 `scripts/validate_package.py` 或等价的只读校验：

- `valid=false`：停止，不打开表单、不调用创建 API。
- `ready=false`：只进入人工复审队列，不提交。
- `ready=true`：按 `image_order`、`detail_images` 和其他字段执行映射。

适配器不得重新计算或改写以下内容：标题、标题候选、风险状态、风险摘要、风险判断、标签、售价、硬闸门、图片顺序、关键词和尺寸字段。后台字段名称不同，只在适配器内部维护映射表。

## 执行与回写

在用户明确授权后，适配器按“打开表单/请求 → 批量填写 → 一次校验 → 提交一次 → 立即下架”的节奏执行。适配器只记录后台结果，不回写或覆盖上品包中的业务判断；使用 `scripts/record_backend_result.py` 将结果写入同一货号目录的 `后台结果.json`，并追加到根目录 `处理日志.jsonl`。结果包括后台名称、创建 ID、提交时间、下架结果和错误信息。

## 最小映射

| 上品包字段 | 适配器动作 |
| --- | --- |
| `title` | 填写后台标题 |
| `brand` | 填写品牌 |
| `category`、`tags` | 选择分类和标签 |
| `sale_price` | 填写售价；`original_price` 保持空 |
| `image_order` | 按六图顺序上传 |
| `detail_images` | 按同一六图顺序填入详情/图集 |
| `shipping_template` | 当前版本保持空 |

适配器不依赖货盘路径、Excel、词库或图片索引，因此后台迁移不会影响前置流程。
